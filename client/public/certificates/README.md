# Certificate files go here

Drop your real certificate files (PDF or scanned image) into this folder using
the filenames below, then set the matching `pdf_url` in
`client/src/components/Certifications.tsx` to `/certificates/<filename>`.

| Certificate                                              | Suggested filename                          |
|-----------------------------------------------------------|----------------------------------------------|
| Certified Junior Mobile Programmer (BNSP)                 | bnsp-junior-mobile-programmer.pdf            |
| Flutter Developer Expert (Dicoding)                        | dicoding-flutter-developer-expert.pdf        |
| Cloud Practitioner Essentials — AWS (Dicoding)             | dicoding-aws-cloud-practitioner.pdf          |
| SOLID Programming Principles (Dicoding)                    | dicoding-solid-principles.pdf                |
| Back-End Application Development (Dicoding)                | dicoding-backend-development.pdf             |
| Merdeka Student Exchange Program Batch 4 (Kampus Merdeka)  | kampus-merdeka-exchange-batch4.pdf           |
| 2nd Best Winner — ICIF 2025                                | icif-2025-2nd-best-winner.jpg                |
| Favorite Junior Developer — ICIF 2024                      | icif-2024-favorite-developer.jpg             |

This folder is served as-is by Vite (no backend/database needed) — any file
placed here is reachable at https://yourdomain.com/certificates/<filename>.
